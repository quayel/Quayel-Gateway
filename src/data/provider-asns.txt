# ── Quayel Gateway — datacenter/hosting provider ASN registry ─────────────────
# Format:  ASN|Label        (one ASN per line, '#' starts a comment)
#
# Datacenter detection is ASN-based. The ASN MMDB resolves any client IP to its
# ASN at runtime; this file maps that ASN to a provider label. IP ranges are NOT
# needed — no matter which block a provider announces, the ASN identifies it.
#
# Adding a provider = adding ONE line here, then rebuild. Find a provider's ASN:
#   whois -h whois.radb.net -- '-i origin ASxxxx'   or   https://bgp.tools/
#
# ASNs listed here set  ip.is_datacenter = true  and  ip.provider = <Label>.
# ASNs from hosting-asns.txt (bad-asn-list) also set is_datacenter, unlabeled.
